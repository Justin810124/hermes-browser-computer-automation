# Security Policy

This project is for user-authorized browser and desktop automation.

## Do Not Use For

- bypassing CAPTCHA, PerimeterX, Cloudflare, or other human verification systems
- entering passwords, 2FA codes, API keys, payment details, tax IDs, or identity documents
- automated purchases, payments, transfers, or account abuse
- scraping or acting on accounts without authorization

## Reporting Issues

If you find a security issue in the skill instructions, open a GitHub issue with:

- the unsafe behavior
- the prompt or workflow that caused it
- the safer behavior you expect

Do not include secrets, cookies, tokens, account data, or screenshots with private information.
